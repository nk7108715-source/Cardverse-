CardVerse Lobby Update

This update adds a premium card-and-chip themed homepage, decorative playing cards and poker chips, and attractive horizontally swipeable game buttons for all six games. Firebase login/signup config is preserved.

To publish: replace index.html in your GitHub repository with this index.html, then commit the change. GitHub Pages will update after deployment.

Important: this is a visual UI update only. Game buttons are previews; multiplayer rooms, actual gameplay, live voice chat, and a secure persistent wallet are not implemented yet. The displayed 500,000 coins are demo-only.
