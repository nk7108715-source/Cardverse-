# CardVerse HTML Demo

- `index.html`: mobile-friendly CardVerse demo.

## Run
Open `index.html` in a web browser, or upload it to GitHub and enable GitHub Pages.

## Limitations
This is a front-end demo. Room codes only work temporarily in the same browser session. Online multiplayer, user accounts, persistent coin balances, and live voice chat are not connected. Virtual coins are for social/demo play only; no real-money betting or cash-out.
